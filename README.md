# Data management portfolio

Source of https://omar-shazly.github.io

An end-to-end data management case study on a **fictional** CySEC-regulated online investment firm, in eight parts: data model and database, data quality, governance, metadata, master and reference data, security and privacy, and a warehouse with a Power BI dashboard.

The company, its people, systems and data are invented. All data is synthetic.

## Layout

- `index.html` – home page and list of parts
- `parts/NN-name/` – one page (and its files) per part
- `assets/` – shared styles

Plain static HTML served by GitHub Pages; no build step.
